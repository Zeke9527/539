# 539 數據研究室（GitHub Pages）

一個免建置、免伺服器的今彩539統計網頁。部署至 GitHub Pages 後，瀏覽器會按月份取得今彩539歷史開獎資料，分析最近 50／100／200／300／500 期，可自訂推薦 1～5 個號碼、調整近期活性化權重，並列出每個推薦號碼的理由。

## 功能

- 自動取得最新今彩539歷史開獎資料。
- 可切換最近 50、100、200、300、500 期。
- 可選擇產生 1～5 個號碼。
- 可用 0%～100% 滑桿調整近期活性化權重；預設長期頻率（所選期數）60%、近期頻率（最近 24 期）40%。
- 將每個號碼在長期與近期樣本中的出現次數轉為 Z-score，再依自訂權重加權排序。
- 每個推薦號碼顯示長期／近期出現次數、頻率分類與距最近一次開出的期數。
- 顯示 01–39 頻率圖、奇偶／大小／和值／區間摘要、最近10期紀錄及低頻號碼。
- 手機與桌面響應式版面；無需 npm、資料庫、API key 或額外建置。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 **Public** 或 **Private** repository（例如 `539-data-lab`）。
2. 將本資料夾中的 `index.html` 與 `README.md` 上傳到 repository 根目錄。
3. 進入 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 的 **Source** 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**。
6. 等待 GitHub Pages 部署完成後，網址通常會是 `https://你的GitHub帳號.github.io/539-data-lab/`。

也可以直接在 GitHub repository 頁面選 **Add file → Upload files**，把兩個檔案拖曳上傳並 Commit changes。

## 資料來源與重要限制

- 網頁目前使用台灣彩券網站使用的資料介面：`https://api.taiwanlottery.com/TLCAPIWeB/Lottery/Daily539Result?month=YYYY-MM&pageSize=N`。
- 這是台灣彩券網站使用的內部 API，並非有版本承諾的公開開發者 API。回應格式、服務可用性及 CORS 跨網域政策可能變更。
- 若官方調整介面或瀏覽器跨網域請求被限制，網頁會顯示更新失敗，不會把舊資料標成最新資料。正式獎號仍應以台灣彩券官方歷史開獎頁為準：<https://www.taiwanlottery.com/lotto/history/history_result/>。

## 推薦算法

對所選期間（預設 100 期）與最近 24 期，分別計算 01–39 每個號碼的出現次數。每個視窗內將次數轉為 Z-score：

`Z = (該號碼出現次數 - 39個號碼的平均次數) / 39個號碼出現次數的標準差`

近期活性化權重由滑桿設定為 `R`（0～1），長期權重則為 `1 - R`：

`綜合分數 = 長期 Z-score × (1 - R) + 近期 Z-score × R`

預設 `R = 0.40`，即長期 60%、近期 40%。`R = 0%` 時只依長期樣本排序；`R = 100%` 時只依最近 24 期排序。依綜合分數由高到低排序，輸出使用者選擇的前 1～5 名。這是透明、可重現的歷史頻率排序，不是經回測證實有效的預測模型，也不代表提高中獎機率。今彩539每期開獎彼此獨立，每個號碼在單期中被開出的理論機率相同。
